risk tiers · 3 levels03 / 08

Three risk tiers, three responses

L1 · Green

Reversible

write draft, generate images, draft docs.
if wrong Ctrl+Z, zero cost.
Strategy: let it run

L2 · Amber

Semi-reversible

Send draft emails, open PR, modify staging data.
Mistakes need apology / rollback.
Strategy: human review

L3 · Red

Irreversible

Send real emails, make payments, drop DBs, delete prod data.
A mistake is truly irreversible.
Strategy: hard block + two-person review

Never let agent escalate itself

L1 tasks must not upgrade themselves to L2. Authorization must be explicit, revocable, and time-limited.

Thirty lines YAML,
hard-block red lines

# safety-policy.yaml · compiled → runtime guard
level_1_allow:
  - tools: [write_draft, generate_image, read_docs]

level_2_require_review:
  - tools: [send_email_draft, open_pr, write_staging_db]
    reviewer: human

level_3_hard_block:
  - tools: [send_real_email, transfer_money, delete_prod]
    unless: two_human_sign_off AND within_24h

forbidden_always:
  - "rm -rf /"
  - "drop table"
  - "force push origin main"

Before launch must pass 7 questions

✓
Can it delete things? Is there a human review ? Can it 60 seconds?
✓
Its prompt injection make it exceed its privileges? (Run red-team prompts)
!
Does it handle PII ? Are there also PII?
✓
On upstream/downstream failure, will it start messing with other resources?
!
Concurrent 100 agent running together—will it deadlock?
✓
If it errs, can it instantly stop? (kill switch Can it 2 seconds?)
!
Is anyone on call when it fails? Does the runbook have an agent agent-specific section?
