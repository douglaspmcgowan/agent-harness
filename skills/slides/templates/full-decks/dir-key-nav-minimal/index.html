The Fix

The answer isn't
bigger window.

Instead: put your knowledge, preferences, and historyinto a file system.
Let LLM let the LLM read that system before every chat.

× window stuffing

Stuff everything into prompt, expensive, slow, eventually overflows.

✓ File + retrieval

Load on demand, never overflow, structured and diff.

Minimal Setup

4 lines YAML
to get started.

memory:
  root: ~/.llm-wiki
  format: markdown
  retrieval: hybrid  # embedding + bm25

You now have a second brain. Every conversation reads and updates it.
