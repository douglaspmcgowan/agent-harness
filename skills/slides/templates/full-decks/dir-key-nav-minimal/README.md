# dir-key-nav-minimal

8 slides, each with a solid color/gradient mono-background(indigo / cream / crimson / emerald / slate / violet / white / charcoal). Inspired directly by `20260405 Presentation Slides [Arrow-Key Edition].html` —— eight `t-*` theme classes, one background per slide, arrow-key navigation, minimal editorial feel.

**Visual traits:** each slide its own background color + single accent, huge 160px titles with no imagery,4px thick short accent line divider, arrow-prefixed mono list, bottom-left `← →` keyboard hint + bottom-right page label, full-screen breathing negative space, JetBrains Mono for numbers / code / keyboard hint, each background has its own `.dk-accent` color.

**Use when:** You have something to say, few visuals, and want typographic rhythm to guide attention;keynote -style minimal talk; one idea per slide; public sharing / keynote / speech scripts.
