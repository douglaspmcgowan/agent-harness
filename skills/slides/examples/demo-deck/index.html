How · Core idea

Put "how it looks" into :root

Concept

Every visual property——color, font, radius, shadow——become a semantic variable.

  • --text-1 / --text-2 / --text-3
  • --surface / --surface-2
  • --accent / --accent-2 / --accent-3
  • --radius / --shadow / --grad

Example

/* assets/themes/aurora.css */
:root {
  --bg: #06091c;
  --text-1: #e8f0ff;
  --accent: #5ef2c6;
  --accent-2: #7aa2ff;
  --accent-3: #c984ff;
  --radius: 20px;
}

——The whole aurora theme is just that small.

how
The key:base.css reads variable names, not color values. Switching themes = just swap the variables.
