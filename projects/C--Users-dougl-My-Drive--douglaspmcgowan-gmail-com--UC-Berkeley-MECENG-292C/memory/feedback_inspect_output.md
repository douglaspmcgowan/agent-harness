---
name: Visually inspect generated documents
description: After creating Word docs or other output files, always visually inspect the result before declaring done
type: feedback
---

Always visually inspect generated documents (docx, pdf, etc.) after creating them to verify quality before telling the user it's done. Convert to images and review if possible.

**Why:** User pointed out that the first version had poorly cropped images and wasn't inspected. Quality issues were only caught when user screenshotted the doc.

**How to apply:** After generating any document output, convert to PDF/images and visually verify layout, image crops, formatting, etc. Fix issues before presenting to the user.
