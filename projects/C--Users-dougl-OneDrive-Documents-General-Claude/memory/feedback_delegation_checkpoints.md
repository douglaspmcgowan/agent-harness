Before any task ≥200 lines of code, ≥500 words prose, 5+ file bulk edit, or post-compaction resume: run the two-question test in `CLAUDE-delegation.md`.

**Why:** These are exactly the tasks where Codex or Opus delegation saves time and prevents context blowout.

**How to apply:** Read `~/.claude/CLAUDE-delegation.md` two-question test. If both answers are yes → delegate. If brief is mushy → stay on Claude and clarify first.
