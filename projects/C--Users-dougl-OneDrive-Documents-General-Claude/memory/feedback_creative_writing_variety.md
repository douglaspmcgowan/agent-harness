For taglines, names, headlines, or any copy task: default to 5–10 varied options, not one.

**Why:** One option is a take-it-or-leave-it. Five options with different tones/angles lets Doug pick or combine the best elements.

**How to apply:** Any time the request is creative and subjective, generate a range. Label each with its tone/angle (e.g., "punchy," "academic," "provocative"). Don't pick a winner unless asked.
