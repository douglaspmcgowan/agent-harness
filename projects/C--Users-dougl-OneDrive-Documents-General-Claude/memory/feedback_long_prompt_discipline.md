Any user message with 5+ distinct items or tasks: first action is writing or updating `CURRENT-TASK.md` in the project root, before touching any code or files.

**Why:** Long task lists without a written plan get partially completed, then lost to compaction or context drift.

**How to apply:** Count items in the request. If ≥5, write CURRENT-TASK.md first. Reference it throughout. Delete when all items are done.
