NEVER change the aspect ratio of an image to make it fit on a slide or in a layout. Always preserve the original aspect ratio.

**Why:** User explicitly stated this rule. Images were squeezed to fit slide dimensions, distorting the original figure. This is unacceptable.

**How to apply:** When placing images in presentations or documents:
1. Calculate the correct dimensions from the original aspect ratio
2. Scale uniformly (both width and height by the same factor)
3. If the image doesn't fit the available space at its native ratio, make the space fit the image — not the other way around
4. Use letterboxing/pillarboxing if needed rather than stretching
