When the user asks a question in chat about a site we're building together (e.g. "how did X build theirs? could you build that?"), answer in the chat response only. Do NOT also add a section to the site with that answer unless the user explicitly asks to put it on the site.

**Why:** Confirmed on ai-industry-map project 2026-04-17. User asked about Matt Turck's MAD tech stack in chat; I both answered in chat AND added a "How Matt Turck built it" section to visualizations.html. User pushed back: "get the answered question about matt turck's site out of the site. i never asked you to do that."

**How to apply:** Default to chat-only for meta/research questions. The site is for the map itself, not for answers to the user's one-off questions about the map. When in doubt, ask whether they want it on the site.
